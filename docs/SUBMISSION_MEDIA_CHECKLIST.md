# Submission media checklist

Use only the hosted synthetic demo. Check every capture for browser bookmarks, notifications, local paths, cookies, account names, IP addresses, or real financial data before publication.

## Recommended screenshots

- [ ] Clean main UI showing Olos branding, monthly summary, Quick Add, upcoming items, and synthetic Recent Activity.
- [ ] Expanded technical/data area showing “WebMCP ready · 11 structured tools” and “Disposable demo session.”
- [ ] Agent tool interaction for `add_transaction`, including structured arguments but no private browser/account chrome.
- [ ] The agent-created transaction visibly reflected in Recent Activity and the monthly summary.
- [ ] Calendar popout with small recurring markers and accessible legend.
- [ ] Credit/loan section showing a synthetic revolving facility and fixed-loan estimate separately.
- [ ] Before/after capture of one linked recurring loan repayment: cashflow once and loan balance once.
- [ ] Compact README architecture diagram.
- [ ] Optional focused code crop of `document.modelContext.registerTool(...)` and annotations; omit machine paths and unrelated code.
- [ ] Public GitHub repository landing page with README and MIT license visible.

## Video capture checks

- [ ] Total runtime 2:30–2:45 and definitely under 3:00.
- [ ] Narration/audio is clear; no copyrighted music.
- [ ] Cursor and text are readable at 1080p.
- [ ] Browser notifications and personal profiles are hidden.
- [ ] The exact agent prompts in `DEMO_VIDEO_SCRIPT.md` are pre-copied.
- [ ] Render is awake and health-checked before recording.
- [ ] A fresh demo session is ready; no prior accidental records.
- [ ] Backup fallback recording exists for the mutation and loan-payment segments.
- [ ] Final YouTube visibility is Public and the URL is tested signed out.

## Submission asset checks

- [ ] Primary image communicates “human UI + agent tools” without stock AI imagery.
- [ ] Screenshots use synthetic names and amounts only.
- [ ] Repository URL is correct.
- [ ] Live URL is correct and reachable signed out.
- [ ] Video URL is correct and playable signed out.
- [ ] Devpost text does not claim browser/deployment tests that were not performed.
